# 계정 없이 글 단위 비밀번호로 권한을 증명한다

방명록은 누구나 빠르게 글을 남기는 용도이므로, 회원가입/로그인 시스템을
만들지 않기로 했다. 대신 글을 쓸 때마다 비밀번호를 함께 입력받아 그 글의
`password_hash` 컬럼에 저장하고, 수정·삭제 요청이 오면 입력된 비밀번호를
해시해 비교한다.

- 비밀번호는 평문으로 저장하지 않는다. Node의 `crypto.scryptSync`로 매
  글마다 다른 salt를 붙여 해시한다(추가 의존성 없이 표준 라이브러리만
  사용).
- 세션/쿠키가 없으므로 수정·삭제할 때마다 매번 비밀번호를 다시 입력받는다.
  같은 브라우저라고 "기억"하지 않는다 — 단순함과, 다른 사람 컴퓨터에서
  깜빡하고 로그아웃 안 한 상태로 남는 위험을 없애는 것을 동시에 얻는
  트레이드오프.
- 비밀번호가 틀리면 403과 함께 "비밀번호가 일치하지 않습니다"를 반환하고,
  어떤 필드가 틀렸는지(이름? 비밀번호?)는 더 캐지 않는다 — 존재하는
  글인지 추측할 단서를 최소화하기 위함.
